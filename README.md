# Smart Online Solutions — starter website

A responsive, bilingual static website starter for GitHub Pages.

## Files
- `index.html` — language selection page
- `fa/index.html` — Persian homepage (RTL)
- `en/index.html` — English homepage (LTR)
- `css/main.css` — shared visual system and responsive styles
- `js/main.js` — mobile navigation and current copyright year
- `assets/images/sos-logo.png` — supplied SOS logo
- `assets/icons/favicon.svg` — simple site favicon

## Preview locally
Open `index.html` in a browser. Choose فارسی or English. No build step is required.

## Publish with GitHub Pages
1. Back up the current repository before replacing anything.
2. Copy the contents of this folder into the repository that is configured for GitHub Pages.
3. Commit and push the changes.
4. In the repository, open **Settings → Pages** and confirm the published source/branch.
5. Open the published URL and test the language links, navigation, email link, and mobile layout.

The paths in this project are relative, so they also work when the site is published as a GitHub Pages project site under a repository path.

## Important notes
- The portfolio cards are explicitly labelled as concept demos. They are not claims of completed client work.
- The contact action uses `mailto:smartonlinesolution.sos@gmail.com`. It opens the visitor's configured email app; it does not send a message automatically.
- The font stylesheet currently loads Inter and Vazirmatn from Google Fonts. If you want fully self-hosted fonts, download licensed font files and update the CSS before launch.
- Replace or refine service descriptions before launch so they exactly match the services you currently offer.
- No backend, analytics, form submission service, or Telegram bot is configured.
